# Repository guidelines

## Current architecture

The owner's approved Carbon & Violet implementation supersedes the former CDN/Tailwind design. This is static HTML, CSS and vanilla JavaScript with locally pinned Three.js 0.180.0. Do not introduce frameworks, npm/build requirements, backend/database, forms, tracking or remote runtime dependencies. Publish main / root on GitHub Pages; preserve .nojekyll and the /portfolio/ base.

## Preservation and content

Preserve Git history, existing files, navigation, static SVG/Core fallback, filtering, disclosures and architecture explorer accessibility. Root HTML aliases preserve old URLs. Historical documents/assets may describe the previous website and are not the current architecture. Never invent project capabilities, achievements or metrics. REVENANT is conceptual until supported by independent implementation evidence. ShadowWatch is simulation, Crypto is research/paper trading and TRACEZERO distinguishes initial phases from planned work.

Engineering Notes and challenge-story sections were removed by owner instruction. No individual project repository/documentation links yet. Use only supplied original logos and approved public CV. Never publish private source PDFs, planning documents, credentials or unapproved personal fields.

## Editing and verification

Use semantic HTML, reusable ordinary CSS, local ES modules and document-relative routes. Use textContent for dynamic strings. Preserve keyboard focus, Escape/history behavior, no-JS content, reduced-motion support and reserved illustration geometry. Keep repeated menus/footer markup synchronized. No build-time framework is required.

The private workspace contains source and adapter regression tools and a public-only exporter. Run relevant suites there before exporting. Record actual local/live checks in PROJECT_STATUS.md. Browser/AT/console/print/GPU/performance results must not be inferred from source tests. Use concise imperative commits and normal pushes; no history rewriting.

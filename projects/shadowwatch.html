01 / purpose

A practice environment for analyst decisions.

ShadowWatch provides a gamified environment for practicing alert triage, incident tickets, log classification and indicator investigation. It brings these exercises into one analyst workspace rather than presenting a real operational SOC.

Intended users are analysts learning security operations and administrators preparing training sessions. All alerts, threats, incidents and response actions are simulated; no real systems are monitored or affected.

README / pp. 1–2, 5–6; Technical Documentation / §§1–5

02 / workflow

Follow the source-defined workflow.

  1. Prepare a session

    Administrators generate simulated alerts and training logs.

  2. Triage alerts

    Review severity and context, then acknowledge an alert.

  3. Choose a simulated response

    Resolve the training alert with a response action; it does not isolate a real host.

  4. Manage incidents

    Create tickets for complex simulated threats and track investigation status.

  5. Inspect logs and indicators

    Classify simulated logs and look up IP, domain or hash indicators in the training intelligence database.

  6. Review progression

    Points, badges and leaderboard activity provide practice feedback, not evidence of professional detection accuracy.

05 / security

Controls with explicit evidence levels.

These descriptions retain the source’s evidence level. Documented controls and design intentions are not an independent security audit.

Authentication / documented
Password hashing with PHP password_hash/password_verify; the README names bcrypt and describes login session regeneration and HTTPOnly cookies.
Request and query controls / documented
CSRF tokens, parameterized PDO queries and output escaping are described. API-layer coverage was not independently reviewed.
Roles / documented
Analyst, Senior Analyst and Admin access appear in the README. The technical reference lists additional role/schema variation; no definitive deployed matrix is asserted.
Local training boundary
The reference flags development-only utilities, demo-account configuration and verbose development errors as deployment risks. Remediation is not claimed complete.
